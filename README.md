# AI Research Assistant

## Overview
An AI-powered Research Assistant built using RAG architecture.

## Features
- PDF Upload
- Text Extraction
- Text Chunking
- Vector Search
- Question Answering
- ChromaDB Integration
- Gemini API Integration

## Technology Stack
- Python
- Streamlit
- LangChain
- ChromaDB
- HuggingFace Embeddings
- Google Gemini API

## Workflow
1. Upload PDF
2. Extract Text
3. Create Chunks
4. Generate Embeddings
5. Store in ChromaDB
6. Retrieve Relevant Context
7. Generate AI Response

## Run Project

pip install -r requirements.txt

python -m streamlit run app.py
